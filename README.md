# نظام إدارة النتائج

## تشغيل المشروع
1. فك ضغط المجلد.
2. افتح `index.html` باستخدام المتصفح، أو افتح المجلد في VS Code وشغّله باستخدام Live Server.
3. يحتاج Bootstrap والخط الخارجي إلى اتصال بالإنترنت، بينما ملفات المشروع نفسها محلية.

## هيكل المشروع
- `index.html` واجهة التطبيق.
- `css/style.css` التنسيقات والتصميم المتجاوب.
- `js/main.js` الكلاسات والتحقق من البيانات والتفاعل مع DOM ولجنة الرأفة.

## الوظائف
- إضافة طالب مع التحقق من الاسم والدرجات والحضور.
- استخدام Private Fields وSetters وGetters داخل `Student`.
- استخدام `try/catch` لعرض رسائل الخطأ على الصفحة.
- عرض الطلاب ومتوسطاتهم ونسب حضورهم، مع إمكانية حذف طالب.
- لجنة الرأفة باستخدام `filter` و`map` و`reduce`، مع منع القسمة على صفر.

## ملاحظة
البيانات محفوظة داخل المصفوفة أثناء تشغيل الصفحة فقط، وتُمسح عند إعادة تحميلها. هذا مناسب لنطاق التكليف الحالي الذي لم يطلب قاعدة بيانات أو تخزيناً دائماً.
